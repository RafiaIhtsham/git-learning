What is Git?
    Git is a software that keep tracks of changes in files in a repository in your local computer.
    It can not access or keep track of every single file on your computer, it can only track files in repositories.

What is GitHub?
    This is a platform that stores Git repositories online. It is where different people can share their repositories and upload final files.

What is a repository?
    It is a project that Git is tracking. It contains all files you are working on and all of them can be tracked by GiT

What is a commit?
    It is a checkpoint marker. It can help you understand what you changed in a project when you look at them. It saves checkpoint locally

What is the staging area?
    It is a holding area that has selected changes you want to put in commit. It is done when git add command is applied to a file
What is `origin`?
    As mentioned in the file, Origin is a nickname given to Github repository by Git.

What is `git push`?
    This command sends your commits and changed files to Github. It is like sending a message or uploading a file.

What is `git clone`?
    This command copies a Github online repository to your local computer. This way git can track its progress, files and history.You can also edit files locally now and then push the final file to Github

What is a PAT?
    It is a special token that allows you to access your repository. It is highly important and should not be shared with anyone else
